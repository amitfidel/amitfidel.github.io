Privacy policy

Niso, a personal assistant app. Last updated 2026-10-15.

Niso is a private app used only by its owner, Amit Fidel. It is not offered to anyone else, and the only Google account data it handles is his own.

What Google data Niso accesses

  • Google Calendar (read and write): to read his events and to add or update events he asks for.
  • Google Drive (read-only): to find and read files he has placed there for the app to work on.
  • Gmail (read-only): to read his mail so it can be summarised and organised for him.

How it is used and stored

The data is used only to provide these features to the owner. Niso runs on the owner's own computer, and data it retrieves is stored there. It is not sold, not used for advertising, and not shared with or transferred to third parties, except as needed to provide the features described above.

To provide those features, some text (for example an email or an event description) may be sent to AI services the owner uses, such as Anthropic's Claude, so it can be summarised or acted on. That processing happens under the owner's own account with that service, on his behalf, and the data is not used for any other purpose.

Google API Services User Data Policy

Niso's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
